// Roomescape · Booking Console

방을 고르고, 시간을 잡아라.

테마를 선택하고 날짜를 입력하면, 비어 있는 시각이 즉시 표시된다. 흐리게 표시된 시간은 이미 마감된 슬롯.

⌘ 관리자 콘솔

1 · 테마 선택

예약하고 싶은 방탈출 테마를 클릭해.

2 · 날짜 / 이름 입력

날짜를 바꾸면 위 테마의 시간 슬롯이 자동으로 갱신된다.

3 · 시간 선택

예약 가능한 슬롯만 클릭할 수 있다. 마감된 슬롯은 흐리게 표시된다.

먼저 테마를 선택해 줘.

4 · 최근 1주 인기 테마

예약자가 많은 순서대로.
